# CodeArena demo checklist

1. Run `npm install`, copy both `.env.example` files, then run `npm run dev`.
2. Register a fresh account and show that it remains after restarting the backend in demo mode.
3. Open Problems, change JavaScript to C++ or Python, run code, and submit a non-placeholder solution.
4. Open Battles, choose a level, show the live/bot match message, timer, bot progress, and finish result.
5. Open a private room, copy the invite link, and join it from a second browser session.
6. Open Analytics and explain the skill profile, weak-topic reason, and interview readiness score.
7. Use the Network tab to show the API calls and the Socket.IO connection.
8. Explain that local JSON is only the fallback; PostgreSQL/Prisma and Judge0 are the production integration paths.
